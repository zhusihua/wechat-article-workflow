# 跨 Agent 适配

当前 Agent 直接读取并执行统一 SKILL.md，不依赖平台自动发现 Skill。不需要安装三个上游项目的全部 Skill，也不要另启上游主流程或调用上游 run 状态管理；本篇状态统一写入 articles/。

## 能力映射

| 所需能力 | 映射方法 | 缺少时 |
|---|---|---|
| 文件读写 | 当前环境文件工具 | 无法执行完整本地工作流，说明限制 |
| 命令执行 | Shell / terminal / exec | 无法安装、排版和校验，不声称完整交付 |
| 搜索与网页读取 | 当前 Agent 的联网工具 | 删除无法支持的时效性主张，记录研究降级 |
| 位图生成 | 用户指定后端 > 已配置原生工具 > 已授权外部后端 | 保留完整提示词，说明双封面未完成；不自动购买或注册 |
| 查看图片 | 当前环境看图工具 | 程序可查尺寸，不能代替中文内容与构图验收 |
| 预览与浏览器检查 | 内置文件预览 / Playwright / 浏览器 | 至少交付可打开的 HTML；如不能视觉检查则注明未验收 |

Codex 中可以使用原生 imagegen 和应用文件预览。其他环境使用相同能力的实际可用工具，不要调用不存在的工具名。存在图像模型名称不等于当前 Agent 已连接或有权限。

Baoyu 的后端规则由本地统一 Skill 的能力映射补充；保留其提示词、构图与检查要求。封面是生成位图，不用程序占位图冒充艺术封面。精确流程图和数据图仍走程序绘图路线。

## 调用与路径

从 Skill 的真实文件路径（必要时解析符号链接）向上找到仓库根目录。不要复制 Skill 到另一个目录后假设依赖还在；需要全局注册时按目标 Agent 的机制引用完整 checkout，或创建一个只指向本仓库入口的薄包装。

Python：macOS/Linux 为 workflow/.venv/bin/python；Windows 为 workflow/.venv/Scripts/python.exe。
Node 和浏览器路径由 scripts/bootstrap.py 写到 workflow/runtime.json；不要复制他人生成的该文件或虚拟环境。

## 优先级与持久偏好

本次用户要求 > 本地统一工作流与项目偏好 > 相关上游模块规则。用户明确要求只排版时保持原文；默认无参考链接规则不能用于悄悄删除“只排版”原稿中的链接。

没有完整工具权限时，交付已经完成的部分并列出具体缺失能力。只有 delivery.json.ready=true 且实际视觉检查完成，才宣布本地制作完成；这不等于公众号后台或手机验收。
