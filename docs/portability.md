# 可移植性与验收边界

## 接入约定

完整 checkout + 根目录 README + 统一 Skill 是跨 Agent 入口。不要求 Agent 原生支持同名 Skill 格式；能够读取规则并调用工具即可使用。自动发现、全局安装路径和 UI 元数据属于可选平台适配，不是制作层依赖。

安装器按仓库根目录定位文件，生成本机 runtime.json。安装后的虚拟环境与 node_modules 不可复制到另一台机器作为安装替代品。写作和审稿由目标 Agent 执行，迁移后表达与事实核查质量需要另做同素材比较。

## 数据与凭据

Git 默认排除 articles/、brand/、本机 runtime.json、虚拟环境、下载的上游快照、workflow/state/、.env、研究文档和本地 QA 图片。源目录中的私人文件保留不动，不通过批量提交带入仓库。

publish.zip 的文章不展示默认参考链接，但来源账本仍应留在本地文章目录。生成封面要保存提示词；生图额度和凭据属于目标运行环境。

## 依赖

Python 依赖与 Node 依赖分别锁定。Mermaid 从原本的 12.1.0 更新为 12.2.0，以消除 npm audit 报告的 KaTeX 传递依赖低风险提示；更新后的锁文件 audit 为 0 项。上游三个项目的固定 commit 不变。

安装验证还发现原 Soup Sieve 3.0.1 已被上游撤回，原因是早期 Python 3.11 的正则问题；已固定到未撤回的 3.0.2，并将 Python 最低版本明确为 3.11.5。
